# Mashkif

Mashkif is a community internet outage map for Israel. Its goal is to answer one question: is the problem on my side, or is everyone affected?

## Status

This project is in planning. No code, agent, server, or website exists yet, and nothing can be installed or run.

The planned design, decisions, and next steps are in [docs/project-foundation.md](docs/project-foundation.md).

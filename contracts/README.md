# Mashkif protocol contract

`openapi.yaml` is the single source of truth for the protocol between the
Mashkif Windows agent (`agent/`) and the Mashkif server (`server/`). Both
sides derive their types from it. This directory is licensed under MIT (see
`LICENSE`).

## Versioning

- **Protocol version header.** Every agent request sends
  `Mashkif-Protocol-Version: <n>`, where `<n>` is a positive integer. The
  server answers with the version it used in the same header. On a 400 error
  the header carries the server's current version.
- **Stable paths.** Agent paths live under `/api/agent/` and do not contain a
  version. The header is the only version mechanism, so one route can serve
  the current and the previous protocol version. The server must keep
  accepting the previous version, because agents on managed endpoints update
  slowly.
- **Errors.** A missing, malformed, or unsupported version returns 400 with a
  JSON body: a stable `error` code (`protocol_version_missing`,
  `protocol_version_invalid`, or `protocol_version_unsupported`) and the
  `supportedVersions` list.
- `info.version` in `openapi.yaml` is the current protocol version.

## Operations

| Operation | Method and path | Purpose |
|---|---|---|
| `getAgentHealth` | `GET /api/agent/health` | The agent checks that the server is up and accepts its protocol version. |
| `registerAgent` | `POST /api/agent/register` | Open registration: the agent registers by itself, without a key. It generates its install ID and token and saves them before the request; a retry with the same install ID and token succeeds again. The admin can close registration for new agents. |
| `sendHeartbeat` | `POST /api/agent/heartbeat` | Bearer token. Reports that the agent is up, with its area cell, infrastructure, interval, and latency; the answer carries a new sync ID (also for a retry), the server time, and the next interval. |
| `sendEvents` | `POST /api/agent/events` | Bearer token. Delivers events, also those recorded offline, timed by sync ID and monotonic elapsed time; one result per event, `deferred` past the hourly event budget. The agent sends connectivity lost and restored, sleep, resume, shutdown, and service stop. |

The request examples in `examples/agent-<version>/` are what that agent build sends; the register example holds a placeholder token that never authenticates, and the server replay test registers a random token of its own on every run.

Stable error codes are listed in `AgentErrorCode`. Limits: 64 KB per body, 500 events per request, an event budget per agent and hour, rate limits with 429 and `Retry-After`.

Operator endpoints (`/healthz`, `/readyz`) are not part of the agent protocol
and are not in this document.

## Generated TypeScript types

`generated/openapi.d.ts` is generated by `openapi-typescript` and committed.
Do not edit it by hand. After changing `openapi.yaml`, regenerate it:

```sh
pnpm --filter @mashkif/contracts run generate
```

`scripts/verify.sh --area contracts` lints the document with Redocly
(`recommended-strict`, configured in `redocly.yaml`) and fails when the
committed types differ from freshly generated ones.
